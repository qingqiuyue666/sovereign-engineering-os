# Asset Compounding Intake Template V1

Status label: `ASSET_COMPOUNDING_INTAKE_TEMPLATE_READY`

Repository status: `SEIS_REAL_WORLD_VALIDATION_READY`

Real-world status: `HUMAN_ACTION_REQUIRED`

## Purpose

Capture the minimum metadata required before real evidence can become a
compounding asset.

## Intake Record

```text
source:
date:
actor:
workflow:
claim supported:
limitation:
reuse condition:
confidence:
next use:
privacy status:
asset type:
target registry:
reviewer:
```

## Required Fields

- source
- date
- actor
- workflow
- claim supported
- limitation
- reuse condition
- confidence
- next use

## Confidence Labels

- `low`: useful but weak, incomplete, or one-off
- `medium`: real evidence with clear limitation
- `high`: accepted delivery or repeated pattern with review

## Reuse Conditions

Examples:

- reuse only for same workflow type
- reuse only after redaction
- reuse only as checklist, not proof
- reuse only after buyer approval
- do not reuse externally

## Boundary

This template does not create assets by itself. It only controls conversion of
real evidence supplied later.
