# ComfyUI Workflow Requirements

## Allowed Role

ComfyUI role: controlled enhancement/stylization only.

## Requirements

- Stylization must support controlled rendered passes.
- Enhancement must preserve the hero frame.
- Workflow notes must stay suitable for human review.

## Forbidden

- No ComfyUI execution.
- No model execution.
- No network execution.
- No provider execution.
- No prompt-only generation.

## Review Note

ComfyUI is a planning-only dependency in this sample pack.
