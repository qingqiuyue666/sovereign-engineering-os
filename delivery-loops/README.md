# Delivery Loops

## Purpose

Prepare repeatable project loops for real SEIS delivery while keeping actual
delivery status pending until a client project exists.

## First Loop

`first-ai-production-governance-audit-loop.md` is the first delivery loop for
the AI Production Governance Readiness Audit.

## Status

Repository status: `EXECUTION_KIT_READY`.

Real-world status: `REAL_DELIVERY_PENDING`.

Status label: `FIRST_DELIVERY_LOOP_TEMPLATE_READY`.

## Required Loop Artifacts

- client intake
- current-state map
- risk map
- governance gap map
- recommendation report
- evidence matrix
- ROI and risk-reduction hypothesis
- final handoff
- case-study capture
- asset registry update

## Boundary

A delivery loop template is not a completed delivery, proof asset, case
study, ROI record, or customer adoption claim.
