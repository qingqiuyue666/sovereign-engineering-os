# Codex Observability Tooling Map

## Gate

Map local command evidence, CI logs, run ledgers, OpenTelemetry-style traces,
LLM/agent observability references, cost logs, failure ledgers, and review
artifacts before claiming live observability.

## Evidence Path

- `reports/checkpoints/operability-readiness-review-v1.md`
- `reports/checkpoints/runtime-state-ledger-v1.md`
- `reports/checkpoints/global-source-freshness-audit-v1.md`

## Non-Claim Boundary

Production observability is `DOCUMENTED_ONLY` or `PARTIAL` until live telemetry,
trace, log, cost, and failure evidence exists.
