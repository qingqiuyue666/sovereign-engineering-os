# Asset Library Screen

## Purpose

Specify the internal screen that converts delivery records into reusable SEIS
assets.

## Asset Types

- case
- failure rule
- customer problem
- objection
- pricing outcome
- benchmark
- ROI hypothesis or measurement
- tool reliability record
- template reuse
- SOP candidate
- standardization candidate

## Asset Decision Flow

1. Select delivery record.
2. Choose create/update/reject/defer.
3. Attach evidence and limitation.
4. Choose registry target.
5. Check permission and redaction.
6. Submit for review when external-facing.

## Boundary

An asset card is not proof by itself. It must link to delivery evidence,
acceptance status, permission, and limitation.
