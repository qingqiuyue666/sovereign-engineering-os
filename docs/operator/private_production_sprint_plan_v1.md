# Private Production Sprint Plan v1

## Purpose

This 7-day sprint turns the current private control-plane into practical production workflows and reusable output assets.

## Duration

7 days.

## Daily Plan

Day 1: Code Audit operational loop and branch audit report setup.

Day 2: Merge readiness and AI worker result review packet setup.

Day 3: Post-merge retrospective and daily report integration.

Day 4: Creative production bible and shot plan finalization.

Day 5: Houdini / ComfyUI / DaVinci specifications finalized.

Day 6: Creative review rubric and sample asset review preparation.

Day 7: Private production review, next sprint decision, and no-kernel-expansion enforcement.

## Deliverables

- Branch audit report workflow.
- Merge readiness report workflow.
- AI worker result review packet workflow.
- Post-merge retrospective workflow.
- Code audit operational loop manifest.
- Creative production bible.
- Houdini asset specification.
- ComfyUI workflow specification.
- DaVinci finishing checklist.
- Creative review rubric.

## Verification Plan

Run focused tracer tests for completed priority modules, tracer discovery, schema discovery, acceptance discovery, make ci, diff check, and status check. Do not claim success unless the tests actually pass.

## Stop Conditions

Stop if the sprint attempts abstract kernel expansion, weakens blocked capability language, introduces external execution, persists raw prompts or raw provider responses, touches root integrity manifests, changes the Makefile, or lacks deterministic validation.

## Blocked Actions

No live provider calls, no network execution, no process launching, no environment value access, no SQLite, no production autonomy, no financial execution, no trading automation, no Houdini/ComfyUI/DaVinci/AE/Blender/Unreal execution, and no local GUI tools.

## Review Cadence

Daily operator review after each completed day. Human review is required before merge and before any future external production authorization.

## Rollback Plan

Rollback the sprint plan, deterministic builder, and tests together. Keep private operating rules and blocked capability language preserved.
