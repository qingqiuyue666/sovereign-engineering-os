# Governance Gap Template

## Purpose

Capture the distance between current workflow evidence and the readiness
controls required for trustworthy AI-assisted engineering.

## Gap Table

| Gap | Current State | Required State | Evidence Needed | Owner | Priority | Status |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  | high / medium / low | open / pending / closed |

## Required Gap Categories

- buyer/risk ownership
- evidence capture
- review gates
- human approval
- rollback/remediation
- audit trail
- external wording
- proof asset permission

## Completion Rule

Open gaps do not block handoff if they are visible, owned, and accepted by
the buyer. Hidden gaps invalidate readiness claims.
