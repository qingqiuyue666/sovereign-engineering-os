# Codex Merge Release Governance Gate

## Gate

Codex may prepare commits and draft PRs. Merge, release, tag, deployment,
production owner approval, and public readiness remain human gates.

## Evidence Path

- `CODEX_DELIVERY_PROTOCOL.md`
- PR state and review decision
- `reports/checkpoints/whole-content-completion-checklist-v1.md`

## Non-Claim Boundary

Draft PR evidence is not merge approval, release approval, deployment, or public
marketing readiness.
