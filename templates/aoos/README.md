# AOOS Templates

These templates support the Stage 4/5 AOOS skeleton. They are evidence capture
forms, not proof by themselves.

Machine-readable Stage 5 interface schemas live in `docs/aoos/schemas/`, with
the checked fixture at `examples/aoos/stage45-interface-fixture-v1.json`.

- `evidence-report-template.md`
- `failure-learning-log-template.md`
- `incident-record-template.md`
- `reality-validation-log-template.md`
- `domain-acceptance-rubric-template.md`
- `tool-roi-review-template.md`
- `model-tool-routing-decision-template.md`
