# Stage 7 To Stage 8 Transition Rules

Status label: `STAGE_7_TO_8_TRANSITION_RULES_READY`

Repository status: `SEIS_REAL_WORLD_VALIDATION_READY`

Real-world status: `HUMAN_ACTION_REQUIRED`

## Purpose

Define the minimum conditions for moving from Stage 7 - Real-World Validation
to Stage 8 - First Delivery Loop.

## Minimum Transition Condition

Move toward Stage 8 only when all of these are true:

- a real target exists
- real pain exists
- workflow access exists
- scope is accepted or equivalent high-commitment signal exists
- risk boundary is acceptable
- evidence access exists
- buyer or operator agrees to review output

## Not Enough For Stage 8

One discovery conversation alone is not delivery readiness.

The following are also not enough:

- generic interest
- "send me details"
- a free advice call
- social media response
- internal enthusiasm
- target list completion
- outreach sent
- an empty delivery template
- a service page draft

## Required Stage 8 Entry Record

Before delivery begins, create or update:

- `delivery-loops/delivery-scope-template-v1.md`
- `delivery-loops/acceptance-criteria-template-v1.md`
- `delivery-loops/failure-and-rollback-template-v1.md`
- `validation/buyer-budget-trigger-scorecard.md`
- `validation/close-loss-review-template-v1.md` if rejected/no-decision

## Stage 8 Boundary

Stage 8 is a first delivery loop, not:

- repeated delivery
- productization
- SaaS
- certification
- protocol adoption
- credit or clearing
- rights system
- capital allocation

## If Conditions Are Missing

If any minimum condition is missing:

- keep status at `HUMAN_ACTION_REQUIRED`
- record the blocker
- revise target, offer, or message
- do not start delivery
