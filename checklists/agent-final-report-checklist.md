# Agent Final Report Checklist

Every agent final response for repository execution must cover these items.

## Required Items

- final state
- changed files
- commits
- checks
- CI
- risk list
- blocker list
- evidence
- next human gate

## Evidence Rules

- Include command names and outcomes.
- Include PR URL when a PR is opened.
- State CI as passed, pending, failed, unavailable, or not checked.
- State missing evidence directly.
- Do not claim real validation, payment, delivery, production deployment, or
  customer acceptance without source records.
