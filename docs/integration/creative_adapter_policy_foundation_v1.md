# Creative Adapter Policy Foundation v1

## Status

- real creative software runtime: not introduced
- external creative tool control: not admitted
- explicit future admission: required
- source asset overwrite: forbidden
- output manifest: required for any future runtime
- preview/render evidence: required for any future runtime
- logs: required for any future runtime
- human approval: required for any future runtime

## Deferred Policy Families

- ComfyUI workflow/API
- Blender Python/MCP
- Unreal Python/Editor Utility/commandlet
- Houdini HOM/Hython/HDA
- After Effects ExtendScript/UXP/aerender
- ZBrush support/handoff

These policies are declarative only. They do not execute creative software,
control external tools, launch subprocesses, call networks, mutate source assets,
or authorize output overwrites.
