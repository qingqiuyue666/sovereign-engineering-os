# Template Reuse Ledger

## Purpose

Track when SEIS templates are reused, modified, accepted, rejected, or
promoted.

## Ledger

| Date | Project | Template | Use Case | Modified? | Outcome | Evidence | Next Action |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  | yes / no | accepted / revised / rejected / pending |  |  |

## Promotion Criteria

A template can become an SOP candidate only when:

- it is reused in at least two comparable deliveries
- the modification pattern is known
- acceptance or rejection is recorded
- failure modes are documented
- limitations are clear

## Boundary

An unused template is scaffold, not proof. A reused template is evidence only
inside the scope where it was used.
