# portal_lightning_001

Portal rim / lightning arc / energy pulse shot template for production-prototype compositing.

This is a Phase 2 production-prototype template using the already verified local DCC execution paths: Houdini `smoke_cache_test` for physical/cache output, ComfyUI `submit_workflow` for a generated or processed proof image, DaVinci Resolve `project_probe` for scripting/API evidence, and SEOS package/review commands for manifest and review artifacts.

Limitation: Uses the existing Houdini smoke/cache action as the physical portal-energy prototype path; no unsupported lightning solver is claimed.

Runtime outputs belong under `work/phase2/portal_lightning_001/` and must not be committed.
Package and review handoff is represented by ArtifactRefs.
