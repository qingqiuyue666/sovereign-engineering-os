# Codex External Pattern Absorption Layer

Layer id: `EXTERNAL_PATTERN_ABSORPTION_LAYER`

## Purpose

Separate external learning from adoption. External projects can inform criteria
and review queues, but code, dependencies, or operational claims require
license, provenance, security, maintenance, contamination, and local-fit review.

## Connected Loop

project absorption shortlist -> benchmark criteria

The decision record lives in
`reports/checkpoints/external-project-absorption-shortlist-v1.md` and feeds
`CODEX_BENCHMARK_CONTAMINATION_POLICY.md`.

## Evidence Gate

Allowed decisions are `COPY_SMALL_PATTERN`, `INTEGRATE_TOOL`, `REFERENCE_ONLY`,
`NEEDS_REVIEW`, and `REJECT_FOR_NOW`. No dependency or external code is adopted
by this layer.

## Non-Claim Boundary

External pattern intake is reference-only until human/license/security review
authorizes a specific adoption.
