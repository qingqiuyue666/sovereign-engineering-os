# Creative Production Sample Pack v1

This directory contains a private planning-only sample pack for the first 8-12 second VFX / AI / 3D hybrid sample.

## Boundaries

- 8-12 second sample target only.
- One motivated transition is required.
- One strong hero frame is required.
- Houdini is limited to particle / VDB / field assets only.
- ComfyUI is limited to controlled enhancement and stylization only.
- DaVinci is limited to finishing and color planning only.
- AE is limited to final assembly and polish notes only if needed.
- No execution.
- No subprocess.
- No tool launching.
- No provider execution.
- No prompt-only generation.

## Contents

- `sample_project_brief.md`
- `shot_bible_v1.md`
- `houdini_asset_requirements.md`
- `comfyui_workflow_requirements.md`
- `davinci_finishing_requirements.md`
- `ae_assembly_notes.md`
- `asset_directory_contract.md`
- `review_checklist.md`
- `rejection_rules.md`
- `day_by_day_execution_plan.md`

## Use

Use this pack to brief a human-reviewed planning slice only. Nothing in this directory authorizes Houdini, ComfyUI, DaVinci Resolve, After Effects, Blender, Unreal, or any other tool execution.
