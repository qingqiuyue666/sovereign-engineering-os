# Workbenches

## Purpose

Preserve existing local workbench/integration material while pointing future
SEIS app work to the spec-only `app/` directory.

## Current Boundary

The Milestone 7 internal workbench is specified, not implemented. Existing
files in this directory are legacy/local workbench material and do not imply
that the SEIS internal workbench app has been built.

## Reference
