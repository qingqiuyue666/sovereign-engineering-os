# Recommendation Report Template

## Purpose

Provide the client with prioritized recommendations that are tied to
evidence, risk, and acceptance.

## Report Sections

1. Scope and exclusions.
2. Current-state workflow.
3. Readiness summary.
4. Evidence matrix summary.
5. Risk-tier findings.
6. Governance gaps.
7. Review-gate recommendations.
8. Rollback/remediation recommendations.
9. Prioritized action plan.
10. Limitations and pending evidence.

## Wording Rule

Use "recommended", "pending", "supported by", and "not evidenced" rather
than certified, guaranteed, fully compliant, or proven ROI.
