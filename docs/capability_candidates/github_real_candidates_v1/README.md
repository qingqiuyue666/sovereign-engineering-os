# Real GitHub Candidate Evaluation Pack v1

This directory contains real GitHub repository candidate manifests for the
#418 GitHub Capability Intake Packet Lite pipeline.

These files are metadata manifests only. They do not approve, clone, install,
import, execute, or adopt any candidate repository.

The pack records three real candidates:

- `microsoft/playwright` is selected only for a future bounded sandbox smoke
  against local fixture HTML/pages. This is not approval for live website
  automation.
- `ultrafunkamsterdam/nodriver` is retained as a high-risk, reference-only
  candidate because of anti-bot / detection-avoidance orientation and license
  review requirements.
- `ahujasid/blender-mcp` is a high-value creative workflow candidate, but it
  requires a strict sandbox boundary before any live Blender control.

No code is cloned, installed, fetched, imported, or executed by this pack. No
license is approved by this pack. Adapter generation remains disabled.
