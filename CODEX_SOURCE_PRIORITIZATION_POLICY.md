# Codex Source Prioritization Policy

## Gate

Prefer canonical project, standards-body, official documentation, or official
repository sources. Use secondary summaries only as `REFERENCE_ONLY` or
`NEEDS_REVIEW`.

## Evidence Path

- `CODEX_EXTERNAL_SOURCE_INTAKE_REGISTRY.md`
- `reports/checkpoints/global-source-freshness-audit-v1.md`
- `reports/checkpoints/external-source-deep-review-queue-v1.md`

## Non-Claim Boundary

Bounded source review is not exhaustive global search and does not clear
license, security, or benchmark contamination risk.
