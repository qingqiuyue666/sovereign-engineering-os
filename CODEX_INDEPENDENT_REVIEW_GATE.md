# Codex Independent Review Gate

## Gate

Real independent review requires an actual reviewer to inspect the PR and record
a decision. Until then, the state is `HUMAN_REVIEW_REQUIRED`.

## Evidence Path

- `reports/checkpoints/independent-review-simulation-v1.md`
- PR review thread when a real reviewer acts
- `reports/checkpoints/real-world-proof-gap-ledger-v1.md`

## Non-Claim Boundary

Simulated review can improve table-review resistance but cannot replace actual
independent review.
