# Archive

## Purpose

Preserve deprecated or replaced strategic entry points before changing root
navigation.

## Scope

Archive copies from the SEIS assembly pass and future migration notes.

## Non-goals

- Archive files are not current strategy unless referenced by current docs.
- Archive files are not deleted evidence.
- Archive does not imply external validation.

## Contents

- `legacy-readme-before-seis-assembly-2026-06-13.md`
- `legacy-roadmap-before-seis-assembly-2026-06-13.md`

## Operating Rules

- Archive before replacing root-level strategy.
- Keep migration notes in `MIGRATION_MAP.md`.
- Do not delete legacy assets without separate approval.

## Failure Modes

- Operators follow archived strategy as current.
- Archive becomes a dumping ground without replacement references.

## Upgrade Path

Add deprecation headers to older docs only after checks confirm no current
tooling depends on exact wording.
