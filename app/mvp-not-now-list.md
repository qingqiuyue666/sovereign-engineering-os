# MVP Not-Now List

## Purpose

Prevent premature app, SaaS, and platform overbuild.

## Do Not Build Yet

- public SaaS
- customer login
- billing
- marketplace
- certification portal
- live provider orchestration
- autonomous production execution
- secret manager
- browser/OS control plane
- credit, rights, clearing, or capital allocation runtime
- generalized workflow automation platform
- external API connector platform

## Build Later Only If

- repeated delivery loops prove stable workflow patterns
- asset registries show repeated reuse
- buyers ask for the same workflow repeatedly
- support and security boundaries are designed
- human approval and evidence controls are implemented

## Current Status

Spec ready. Implementation pending.
