# Entry Offer Template

## Purpose

Package a bounded offer that can be sold now without pretending SEIS has
completed later-stage infrastructure.

## Scope

First wedge entry offer: AI Production Governance Readiness Audit.

## Non-goals

- No implementation authority over production systems.
- No secret custody.
- No guarantee of compliance certification.

## Template

| Field | Required Content |
| --- | --- |
| Buyer | Economic buyer, technical buyer, risk owner |
| Trigger | Audit, release, incident, AI adoption policy, customer review |
| Problem | AI-written code entering production without enough trust evidence |
| Scope | Current workflow review, risk tiers, evidence map, review gates, rollback plan |
| Deliverables | Scorecard, evidence matrix, prioritized remediation plan, task-package standard |
| Timebox | 5-10 delivery days for entry audit |
| Acceptance | Buyer confirms findings are evidence-backed and actionable |
| Exclusions | No production code authority, no secret access, no live-provider setup by default |
| Proof assets | Redacted before/after, case note, ROI hypothesis, delivery trace |
| Upgrade path | Implementation support, recurring governance review, standardization package |

## Operating Rules

- Do not start without evidence access and named risk owner.
- Keep deliverables auditable and bounded.
- Record any blocker as a failure/learning asset.

## Failure Modes

- Scope expands into implementation without new agreement.
- Buyer expects certification.
- Evidence access is too weak for truthful findings.

## Upgrade Path

Turn repeated audit outputs into a delivery standard candidate.
