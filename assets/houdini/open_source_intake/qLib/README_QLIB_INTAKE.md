
# qLib Open Source Intake v1

Repository:

https://github.com/qLab/qLib

Local source:

Imported from operator-downloaded `qLib-master.zip`.

Purpose:

Use qLib as an open-source Houdini procedural asset library reference for the HFX Factory.

Boundary:

This intake does not automatically merge qLib assets into HFX Core12.

This intake is for license review, technical inventory, interface study, and clean-room rebuild planning.

Rules:

- Do not blindly copy assets into production HFX folders.

- Preserve license information.

- Treat qLib as reference and candidate material.

- Map useful patterns to HFX Core12 only after audit.

- Prefer clean-room rebuild or wrapper adaptation before production use.

- No provider execution.

- No network/runtime execution in repository code.

- No secrets.

- No private local paths.
