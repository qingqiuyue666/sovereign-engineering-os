# Internal Workbench Boundary V1

## Purpose

Connect the `app/` specification to the existing architecture documentation
without adding app runtime code.

## Boundary

The internal workbench is a future operator shell for SEIS records,
evidence, approvals, delivery loops, and asset conversion. It is not the
SEIS kernel, not a public SaaS, not a production control plane, and not a
secret store.

## Implementation Gate

Implementation remains `APP_IMPLEMENTATION_PENDING` until repeated workflow
patterns or internal operator needs justify a narrow prototype.
