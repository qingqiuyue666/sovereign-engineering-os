# Battlefield Scorecard

## Purpose

Score candidate wedges by economic control-point quality and near-term paid
signal probability.

## Scope

Applies to the four current candidate wedges and future wedge proposals.

## Non-goals

- A high score is not market proof.
- A scorecard is not a substitute for paid discovery.
- This file does not authorize broad runtime expansion.

## Scoring Criteria

Score each criterion from 1 to 5. A wedge below 70 total points is not a
first-execution wedge unless a human records a specific override.

| Criterion | Question |
| --- | --- |
| Buyer clarity | Can the buyer and decision chain be named? |
| Budget source | Is there a known budget line or avoided-loss source? |
| Structural pressure | Is pressure increasing without SEIS creating demand from scratch? |
| Buying trigger | Is there a concrete event that forces action? |
| Trust gap | Is trust the reason generic AI is insufficient? |
| Proof speed | Can proof be produced quickly and honestly? |
| Transaction clarity | Can the entry offer be scoped and accepted? |
| Standardization potential | Can delivery become SOP/checklist/evidence standard? |
| Asset compounding | Does every delivery create reusable data or assets? |
| Protocol potential | Could evidence/acceptance become shared format? |
| Credit/rights/clearing potential | Could contribution, ownership, responsibility, or settlement matter later? |
| Stage 10-16 path | Can it plausibly become infrastructure? |
| Anti-platform resilience | Is it hard for platforms to absorb completely? |
| Anti-commodity resilience | Is it hard to replace with cheap generic AI? |
| High-ticket upgrade path | Can the offer expand into higher-value work? |
| Legal/platform risk | Is the risk acceptable and boundable? |
| Delivery complexity | Can early delivery be done without overbuild? |
| Distribution fit | Can SEIS reach the buyer slice? |
| 90-day paid signal | Is a paid signal plausible in 90 days? |
| Long-term control quality | Does it improve control-point position over time? |

## Operating Rules

- Scores must be updated after discovery calls and delivery evidence.
- Scores must not be used to claim market validation.
- The first wedge remains provisional until paid signal exists.

## Failure Modes

- Optimistic scoring hides weak budget access.
- Distribution fit is assumed rather than tested.
- Commodity risk is understated because AI output looks impressive.

## Upgrade Path

Convert scorecards into a versioned evidence-backed wedge ledger after the
first paid test.
