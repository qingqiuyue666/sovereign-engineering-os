# Automation Opportunity Score Screen

## Purpose

Score where automation may help after governance is understood, without
making automation the strategy.

## Score Dimensions

| Dimension | Question |
| --- | --- |
| Buyer pressure | Is there a real trigger? |
| Evidence readiness | Can the workflow produce trustworthy evidence? |
| Risk tier | How dangerous is automation here? |
| Human approval need | Where must human decisions stay final? |
| Repeatability | Could the pattern become a template or SOP? |
| Asset value | Would delivery produce reusable assets? |
| Rejection risk | Does the request violate boundaries? |

## Output

- automate now
- standardize manually first
- audit before automation
- reject
- defer

## Boundary

This screen scores opportunity. It does not authorize automation, production
execution, provider setup, or app runtime expansion.
