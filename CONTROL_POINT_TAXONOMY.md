# Control Point Taxonomy

## Purpose

Define the economic control points SEIS seeks to identify, occupy, defend,
and compound.

## Scope

Applies to market selection, offer design, standards, protocols, proof,
distribution, rights, credit, clearing, and capital allocation.

## Non-goals

- This taxonomy is not proof that any control point has already been
  captured.
- It does not justify entering a market without buyer clarity and a paid
  trigger.

## Taxonomy

| Control Point | What It Controls | Evidence To Seek |
| --- | --- | --- |
| Budget control | Who can approve spend and why | Buyer role, budget owner, procurement route |
| Buying trigger control | The event that forces action | Trigger calendar, incident, compliance deadline, release risk |
| Trust verification control | What makes output acceptable | Acceptance criteria, audit trail, proof package |
| Delivery standard control | How work must be done | SOP, checklist, review gate, certification candidate |
| Data asset control | Accumulated cases, failures, benchmarks | Case library, failure library, ROI history |
| Workflow embedding control | Position inside repeated work | Integration point, task package, handoff contract |
| Distribution control | Repeatable access to buyers | Channel tests, referral loop, service page |
| Customer relationship control | Ongoing trust and repurchase | Maintenance path, review cadence, upgrade path |
| Risk pricing control | Pricing based on complexity and liability | Risk tier, premium trigger, exclusion |
| Rights control | Ownership and usage boundaries | Rights registry, license terms, reuse policy |
| Clearing control | Settlement and responsibility | Clearing logic, acceptance/dispute path |
| Certification control | Who validates capability | Certification criteria, assessment artifacts |
| Protocol control | Shared transaction/evidence format | AI work protocol, delivery package standard |
| Ecosystem control | Partners align to the standard | Partner map, marketplace placeholder |
| Capital allocation control | Investment guided by proof and ROI | ROI signal map, industry opportunity radar |
| World-model advantage | Better read of structural forces | Macro map, platform power map, regulation map |

## Operating Rules

- Score a wedge against all control points before selecting it.
- Favor control points with real budget, trigger urgency, trust gap, and
  standardization potential.
- Reject control points that are easily captured by platforms or generic
  low-price AI services.

## Failure Modes

- Mistaking feature ownership for control-point ownership.
- Entering a wedge where the buyer has no budget or urgent trigger.
- Building protocol language before delivery standards are repeated.

## Upgrade Path

Convert high-scoring control points into acceptance standards, proof assets,
and transaction protocols only after delivery evidence repeats.
