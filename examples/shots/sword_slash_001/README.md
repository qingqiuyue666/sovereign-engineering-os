# sword_slash_001

Fast sword slash / energy trail / impact flash shot template for future live-action or anime-style compositing.

This is a Phase 2 production-prototype template using the already verified local DCC execution paths:

- Houdini `smoke_cache_test` for physical/cache output.
- ComfyUI `submit_workflow` for a generated or processed proof image.
- DaVinci Resolve `project_probe` for scripting/API evidence.
- SEOS package and review commands for manifest and review artifacts.

Limitation: Uses the existing Houdini smoke/cache action as the physical slash-trail prototype path; no unsupported blade solver is claimed.

Runtime outputs belong under `work/phase2/sword_slash_001/` and must not be committed.
Package and review handoff is represented by ArtifactRefs.
