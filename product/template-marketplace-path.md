# Template Marketplace Path

## Purpose

Define the evidence gate for turning repeated templates into marketplace
assets.

## Evidence Required

- template reused across multiple accepted deliveries
- buyer-safe redacted version
- clear use instructions
- known limitations
- support model
- permission to generalize
- no client-confidential content

## Candidate Templates

- AI-code workflow diagnosis
- evidence matrix
- risk-tier map
- review-gate map
- handoff package
- post-delivery review

## Boundary

The repository may hold templates now. A marketplace claim requires external
demand, packaging, permission, and support readiness.
