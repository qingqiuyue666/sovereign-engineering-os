# HFX Factory v001 Core Asset Factory Protocol

This protocol converts the Houdini workflow from one-off FX building into a reusable production FX Factory.

The reference asset is HFX_008 Energy Shockwave.

Every future core asset must follow the same factory model:
- source resolution
- PREVIEW / MID / FINAL_CANDIDATE tiers
- parameter interface
- pass manifest
- cache policy
- comp handoff
- shot binding
- validation
- release package
- final asset system seal
