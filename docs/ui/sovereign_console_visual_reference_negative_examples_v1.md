# Sovereign Console Negative Visual Reference v1

This file records directions that are visually and structurally out of contract.
It is a guardrail for future design prompts and implementation review.

## Forbidden Product Frames

Do not present Sovereign Console as any of these:

- mobile app
- web app
- SaaS dashboard
- chatbot clone
- plugin marketplace
- raw Qt form
- database admin panel
- black sci-fi concept screen
- cyberpunk console
- game HUD
- scattered menu collection

## Forbidden First-Level Page Sprawl

These labels may appear only as absorbed concepts inside their contracted homes,
never as primary navigation:

- Dashboard
- Job Queue
- HFX Factory
- HFX_008 Landing Chain
- Context Packs
- Human Review
- Failure Quarantine
- Artifact Store
- Asset Library
- System Health
- Boundaries

## Forbidden Visual Patterns

- Full-screen black concept art or giant dark regions outside the compact Black
  Box.
- Marketing hero pages, landing pages, mobile card stacks, and web dashboard
  grids.
- Raw Qt engineering forms: label strips, unstyled QPushButton stacks, and
  QFormLayout mission dumps.
- Debug consoles that dominate the app instead of a collapsed Black Box.
- Node-editor treatments for the HFX chain: QGraphicsView surfaces, drag/drop
  graphs, heavy particles, screen shake, and glass-break effects.
- Scattered menus that force operators to hunt for mission state.
- Anime skins that replace the professional workspace base.
- Copyrighted anime character references, anime girl character art, mascot
  takeover, full-screen speed lines, full-screen effects, Japanese text
  gimmicks, and cheap anime skin treatments.

## Required Replacement Direction

Replace every forbidden direction with the contracted pattern:

- Apple Mission Control Workspace
- Finder/Xcode-style sidebar with five entries
- Raycast/Codex-style Command Bar
- Current Mission Card as the hero object
- compact HFX_008 Energy Chain
- visible Coding Activity Panel
- bounded Test Gate Panel
- subtle anime-inspired micro FX only during coding and testing states
- steady Inspector with useful default guidance
- collapsed structured Black Box
- light-gray Apple base and white mission cards
