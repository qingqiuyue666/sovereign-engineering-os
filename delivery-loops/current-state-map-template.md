# Current-State Map Template

## Purpose

Map how AI-assisted engineering work currently moves from idea to production
or use.

## Workflow Map

| Step | Actor | Tool / System | Artifact | Evidence Available | Risk |
| --- | --- | --- | --- | --- | --- |
| Intake |  |  | ticket / request | yes / no / pending |  |
| AI assistance |  |  | prompt / generated code / suggestion | yes / no / pending |  |
| Review |  |  | PR / review note | yes / no / pending |  |
| Test |  |  | test result / CI / manual check | yes / no / pending |  |
| Approval |  |  | approval record | yes / no / pending |  |
| Release / use |  |  | release note / deployment / internal use | yes / no / pending |  |
| Rollback / remediation |  |  | rollback plan / incident record | yes / no / pending |  |

## Required Observations

- where AI output enters
- who reviews it
- what evidence is produced
- what approval is required
- what can fail
- who owns rollback

## Validation

The technical owner must validate the map before the recommendation report
uses it.
