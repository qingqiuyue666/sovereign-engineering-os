# Accepted Risk Register V1

External review required: yes.

Accepted risks are accepted only for readiness to enter external review. They
are not accepted as final public recognition evidence.

| Risk ID | Risk | Acceptance Boundary | Mitigation |
| --- | --- | --- | --- |
| AR-001 | Evidence is repository-local. | Accepted for external review packet assembly. | Require independent verification runbook and PR links. |
| AR-002 | No long-duration operation evidence is included. | Accepted for external review readiness only. | Track as residual risk requiring 30-90 day operation evidence. |
| AR-003 | No live AI provider execution is admitted. | Accepted because live providers are non-goal for this packet. | Keep AI admission policy fail-closed. |
| AR-004 | No OS sandbox, RPA, or computer-control boundary exists. | Accepted as explicit non-goal. | Preserve identity and non-goals documentation. |
| AR-005 | Public GitHub Release is not published. | Accepted because release publication is out of scope. | Preserve tag invariant and release-invariant checks. |
