# First Wedge Transaction Pack

## Purpose

Package the provisional first wedge into a concrete entry transaction that
can be sold, delivered, accepted, rejected, and reviewed without pretending
market proof already exists.

## Wedge

Primary wedge: **AI Engineering Production Governance**.

Primary offer: **AI Production Governance Readiness Audit**.

Status label: `FIRST_WEDGE_TRANSACTION_PACK_READY`.

Repository status: `EXECUTION_KIT_READY`.

Real-world status: `MARKET_PROOF_PENDING`.

## Buyer

The first buyer is an engineering, product-engineering, platform, security,
or founder-level leader who owns the risk of AI-written or AI-assisted code
entering production. The buyer must have authority over workflow changes or
direct access to the person who does.

## Budget

Likely budget sources:

- engineering productivity
- developer tooling
- security and compliance readiness
- release quality
- incident prevention
- audit preparation
- AI adoption governance

## Buying Trigger

The strongest trigger is a near-term production, audit, customer-review,
board, incident, or internal policy pressure where the team must show how AI
code is admitted, reviewed, tested, rolled back, and accepted.

## Trust Gap

The buyer does not need another generic AI tool claim. The buyer needs a
credible way to prove that AI-assisted engineering work is governed by
evidence, review gates, rollback, ownership, and acceptance criteria.

## Scoped Offer

The readiness audit is a 5-10 delivery day review of one bounded AI-code or
AI-assisted engineering workflow. It produces a scored governance report,
evidence matrix, risk tiers, review-gate map, rollback/remediation plan,
and prioritized next actions.

## Exclusions

- no production system authority
- no secret handling or credential custody
- no live provider integration setup by default
- no compliance certification
- no guarantee of customer, revenue, audit, or Stage 16 outcomes

## Proof Assets Generated

Every accepted delivery should generate, subject to redaction and buyer
approval:

- governance scorecard
- evidence matrix
- before/after workflow map
- redacted case note
- objection and pricing record
- risk-reduction hypothesis
- reusable task-package standard candidate

These assets remain `EVIDENCE_PENDING` until a real buyer, real scope, and
real acceptance record exist.

Use `validation/` before treating the wedge as proven. The required next
