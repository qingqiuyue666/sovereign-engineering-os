# Buyer One-Pager V1

Status: `implemented_local`

## Offer

AI Agent Execution Control Plane for teams that want coding agents and local
automation to work under policy gates, evidence ledgers, recovery records,
human approval boundaries, and non-claim discipline.

## Pain

More agents and tools create more risk: unsafe commands, unclear approvals,
missing evidence, prompt injection, secret exposure, failed recovery, benchmark
overclaims, and ungoverned external actions.

## What The Pilot Shows

- controlled local low-risk execution;
- dangerous task denial;
- dry-run failure and resume record;
- evidence and failure ledgers;
- audit export path;
- buyer demo and pilot workflows;
- real-world validation tracker;
- commercial material non-claim audit.

## Current Boundary

This is a local, reviewable control-plane package. It is not a production
deployment, external benchmark result, security certification, customer
validation, paid customer proof, or enterprise procurement approval.

## Pilot Hypothesis

Target buyer will value a control layer above Codex, Claude Code, GitHub
Actions, MCP tools, and future executors more than another coding agent because
the buyer needs governance, auditability, recovery, and claim discipline.
